# EraUma

EraUma将保持内源，ERE引擎将保持开源；请各位开发者以internal或private方式fork本项目，不要以public方式fork本项目，以避免不必要的麻烦！

## Road Map

EraUma预定每个月末发一次版本，版本号每次递增0.1，至第一个正式发布版本为止

0.5将是下一个预览版本；自0.5开始，每个预览版本可能拥有.5版本，用于版本间的bug修复

不遵循以上预览版本号命名规则的版本号均非本制作组制作发布的EraUma游戏

自v0.3版本起的版本列表及（预期）主要改动点如下所示

* v0.3：首个公开发布的预览版本
* v0.4（适配引擎v1.0.2-noa）：bug修复版本，含一个额外发布的bug补丁包，内容上与v0.3基本相同（有些微调整），增加了免责声明和指路链接
* ~~v0.4.7~~：某资源站赋予的版本，猜测内容与v0.4相同，不知是否包含bug补丁包
* **v0.4.8（当前版本，适配引擎v1.0.2-mebius）**：提前放出的非主要版本，远征机制、压力值机制、金星公园口上、强制BE机制、部分角色读档时的meta对话
* _v0.5（开发中）_：下个主要预览版本，v0.4.8的bug修复版本，游戏引导用的小纸条机制、压力值机制、超得、调教立绘背景更新
* v0.6：预定实装两个角色的口上，其他角色专属口上的bug修复和润色
* v0.7：预定实装理事长和绿帽等特殊角色的交互、招募，以及其具有的特殊机制（超得等）
* v0.8：预定实装地下室机制
* v0.9：预定实装特定角色扮演功能，取名彩蛋机制

## Tutorial

EraUma发布采取分包制，即游戏本体包+游戏资源包拆分打包方式，使用时需要解压到同一个文件夹，才能通过[ERE引擎](https://gitgud.io/SLeader/era-electron/-/releases/permalink/latest)启动

从ERE引擎顶部下拉菜单中【打开游戏文件夹】启动时，请确认打开的文件夹至少有以下结构：

* erauma文件夹
    * csv文件夹
        * Chara文件夹
        * _config.json
        * _fixed.json
        * 其他各种以csv为后缀名的文件
    * ere文件夹
        * data文件夹
        * event文件夹
        * page文件夹
        * system文件夹
        * utils文件夹
        * era-electron.js
        * main.js
    * （可选）res文件夹

如果文件夹不是以上结构，则无法顺利在ere引擎中打开运行
